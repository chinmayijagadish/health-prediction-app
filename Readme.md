# Health Prediction App

A healthcare prediction application developed using Flask, SQLite, and Gemini AI.

## Project Goal

The application stores patient blood test records and generates AI-powered health remarks.

## Tech Stack

- Python
- Flask
- SQLite
- Gemini API
